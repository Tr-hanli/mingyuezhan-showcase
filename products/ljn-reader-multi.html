  4. CFe-A/CFe-B 接口传输速度达 900 MB/s；SD/TF 4.0 接口（UHS-II 标准）理论速率达 312 MB/s。

使用教程

  1. 使用随附 USB-A 或 Type-C 数据线连接读卡器与电脑/手机/平板。
  2. 部分手机或平板需要打开 OTG（多数安卓手机自动启用，iPad 需用 Type-C 接口）。
  3. 插入内存卡，CFe-A 和 CFe-B 卡同时插入时优先读取 CFe-A。
  4. 指示灯亮蓝色 = 待机，亮绿色 = 正在读取数据。
⚠️ 注意事项
  • CFe-A 卡和 CFe-B 卡无法同时读取，同时插入时优先读取 CFe-A。
  • 支持 UHS-II SD/TF 4.0 高速传输，向下兼容 UHS-I SD/TF 3.0。
  • CFe-B 卡因高速读写需 1.5 A 峰值电流，超出台式电脑 USB 接口 0.9 A 供电上限，读取 CFe-B 需要辅助供电。
  • 仅 CFe-A 和 TF 卡是回弹式卡槽，其他不是。
  • 支持 ddr200 读取。

FAQ

客户说无法读取这种卡，只能退换是嘛，是否可以读这种卡呢？
不支持 XQD 卡。
为什么我搭配的内存卡，读取的速度那么慢？
R604 所说的「4.0 高速」指的是卡槽支持读取 SD/TF 4.0（UHS-II），理论最高速率可达 312 MB/s。实际传输速度需要同时满足三个条件：①内存卡本身必须是 SD/TF 4.0（UHS-II）标准（卡背面有两排金属触点）；②电脑接口必须为 USB 3.2 Gen1 或更高；③内存卡的读写速度尽可能接近 312 MB/s。如果内存卡是 UHS-I（单排触点）或电脑接口是 USB 2.0，整体速度会受限于最低环节，通常在 20~100 MB/s 之间。
读取 CFe-B 卡可以不供电使用吗？会影响读取/传输速度吗？
在不供电情况下也能正常使用，正常情况下不会影响传输速度（峰值速度由 USB 接口协议和卡本身决定）。但建议在读取 CFe-B 卡大文件时接上供电，避免瞬时电流不足导致数据校验出错、传输中断或设备意外弹出。

FAQ

四合一读卡器能读取 CF-A 卡吗？
该读卡器仅支持 CF-C 卡，暂不支持 CF-A 卡。
Type-C 接口读取速度有吗？
Type-C 与 USB 接口速度一致，具体取决于协议版本。
读卡器的 VID PID 设备序列号是否唯一？
VID 和 PID 组合唯一，序列号可能重复，建议以实际检测为准。
请问读卡器最大可以读多大的 TF 卡？
读卡器通常兼容 2 TB TF 卡，具体请以产品规格为准。
双排金手指的 SD 卡是否支持？
双排 SD 卡可兼容读取，但速度受限于单排接口。
是 UHS-I 还是 UHS-II？
本款为 UHS-I，可兼容 UHS-II 配件。
这款 CF-B 的可以用吗，还是只能 CF-C 的？
CF-B 可用，但 CF-C 是专用型号，建议使用 CF-C。
传输速度不稳定，到 20% 左右速度就会降下来？
初始传输因系统缓存加速较快，缓存填满后速度会正常下降。
换了多个接口插入，都会显示驱动错误（U盘存在问题）？
建议不插卡测试，若提示消失则为卡问题，可扫描或暂时忽略继续使用。

七、通用 FAQ（速度/UHS/容量/驱动）

什么是「4.0 高速」读卡器？
这里的「4.0」指的是卡槽支持的协议，即 SD 4.0 / TF 4.0 = UHS-II。要达到理论最高速度（312 MB/s）必须满足三个条件：①UHS-II 内存卡（背面双排触点）；②USB 3.2 Gen1 及以上接口；③内存卡本身读写速度接近 312 MB/s。
UHS-I 和 UHS-II 怎么识别？
看内存卡背面的金属触点：单排 = UHS-I，双排 = UHS-II。UHS-II 卡的读取速度通常在 150-300 MB/s；UHS-I 卡一般在 80-104 MB/s。
最大支持多少容量？
R604 支持 4 TB；CC1026/CC1027/R305 支持 2 TB。注意 TF 卡 SDXC 规范下最大 2 TB。
显示驱动错误（U盘存在问题）怎么办？
先不插卡测试读卡器是否正常。如果不报错，则是卡的问题（建议扫描或忽略继续使用）；如果仍然报错，则是读卡器或接口问题。
WiFi SD 卡能读取吗？
绿巨能所有读卡器目前均不支持读取 WiFi SD 卡。WiFi SD 卡需要专用 App 通过 WiFi 连接读取。
速度不稳定（20% 左右降速）是怎么回事？
正常现象。操作系统会先用内存缓存加速数据传输，缓存填满后速度会下降。属于预期行为，并非故障。
Type-C 与 USB-A 速度有差异吗？
在协议版本相同的情况下，两者速度一致（均为 USB3.0 = 5 Gbps；USB3.2 Gen2 = 10 Gbps）。实际差异主要来自接口协议版本。
手机连接没反应怎么办？
①确认手机支持 OTG（多数安卓自动启用，部分需在设置中手动开启）；②使用原装或合规数据线；③尝试更换手机或平板测试。如仍无效，建议先用电脑测试读卡器本身。
支持 RAW / 视频等大文件吗？
绿巨能读卡器传输的是原始数据，与文件格式无关，RAW / 4K 视频等均可传输。能否在设备上打开，取决于设备/电脑的解码软件。
弹出设备时指示灯不灭是故障吗？
不是故障。R305 等型号设计为弹出时不灭灯，属于正常现象。
