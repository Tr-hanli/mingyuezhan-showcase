猛玛 MELO P1 无线麦克风/声卡系统

猛玛 MELO P1 无线麦克风系统 — 产品资料文档

资料来源：https://www.hollyland.com.cn/support/melo-p1/ 品牌：HOLLYLAND 猛玛 整理日期：2026-08-12

一、产品概述

MELO P1 是猛玛推出的无线麦克风/声卡系统，采用设备间全无线连接方案，实现麦克风、监听耳机与声卡之间的真无线连接。首创声卡行业一体式收纳充电盒形态，设备从盒中取出即可自动配对连接。

系统组件： 1. 无线麦克风（手持麦，可更换电容/动圈麦头） 2. 无线声卡 3. 无线监听耳机 4. 蓝牙遥控器 5. 收纳盒（兼充电盒）

四、常见问题（FAQ）

4.1 功能与使用

Q1：MELO P1 有一键降噪功能吗？

有。MELO P1 的无线手持麦具备一键降噪功能，降噪深度最大可达 25 dB，可使用【猛玛音频】App 进行无级调节。

Q2：MELO P1 需要安装声卡驱动使用吗？

不需要安装驱动。MELO P1 可直接通过连接手机 APP【猛玛音频】进行调音操作，无需安装声卡驱动即可连接手机和电脑使用。

Q3：MELO P1 有预置的声卡效果包可以使用吗？

有。MELO P1 的声卡效果包名为【预设】，可使用手机 APP【猛玛音频】连接声卡直接选择喜欢的预设进行应用，快速获得想要的调音效果。

Q4：MELO P1 各设备可以通过充电盒同时充电吗？

可以。MELO P1 首创声卡行业内的一体式收纳充电盒形态，支持通过充电收纳盒给麦克风、监听耳机以及声卡三个设备同时充电。

Q5：MELO P1 需要自己去给声卡外接麦克风和监听耳机吗？

不需要。MELO P1 采用设备间全无线连接方案，实现麦克风、监听耳机和声卡之间的真全无线连接，无需接线。设备从盒中拿出即可自动配对连接，开始使用。

Q6：MELO P1 能够自定义调音吗？

支持。MELO P1 支持两种模式自定义调音：

  • 快速自定义调音：使用官方预设效果 + 简洁调音模块
  • 精细自定义调音：使用官方预设效果 + 专业调音界面

4.3 连接与兼容性

Q8：一台声卡设备最多可同时连接多少个无线麦克风？

2 个。一台声卡设备最多可同时无线连接 2 个无线麦克风使用。

Q9：一台声卡设备最多可同时连接多少个无线监听耳机？

2 个（一对）。一台声卡设备最多可同时无线连接 2 个（一对）无线监听耳机使用。

Q10：一台声卡设备最多可同时连接多少个遥控器？

1 个。一台声卡设备最多可同时无线连接 1 个遥控器使用。

Q11：MELO P1 标配的无线手持麦可以更换麦头吗？

可以更换。标配无线手持麦有电容麦头和动圈麦头两种类型可选：

  • 电容麦头：更适用于室内安静环境下直播使用
  • 动圈麦头：更适用于户外嘈杂环境下直播使用

Q12：MELO P1 标配的遥控器可以充电吗？

不能充电。标配遥控器采用纽扣电池供电，型号为 CR2032。

Q13：MELO P1 支持双人演唱直播场景吗？

支持。声卡最多可配对两只无线手持麦克风，供双人主播同时演唱。但此场景下，需在声卡侧面 3.5 mm 接口处另接一对监听耳机给第二位主播进行效果监听。

Q14：MELO P1 支持连接电脑使用吗？

支持。使用移动设备（手机/平板）上的【猛玛音频】APP 调完音后，直接用数据线将声卡连接电脑即可使用。连接电脑时无需安装复杂驱动与机架软件，选择名字带 Audio Interface 的声卡音频输入/输出源即可获取声卡混音后的音频。

4.4 麦头类型识别

Q15：如何区分 MELO P1 的手持麦麦头是电容还是动圈？

拆解步骤：

  1. 抓紧麦头，将无线手持麦克风的握持部分外壳向顺时针（从麦头向下看）方向稍微用力拧松，再慢慢旋转，即可将握持部分外壳拆卸下来；
  2. 再将麦克风露出的磨砂感麦头固定金属环，也向顺时针（从麦头向下看）方向稍微用力拧松，再慢慢旋转，即可将固定金属环与麦头部分完全分离；
  3. 最后将麦头部分轻轻向上拔出，即可卸下麦头。

判断方法：

判断方式 电容麦头 动圈麦头
麦头底部字母标识 CM DM
重量 较轻 较重
标配防滑橡胶圈标识 带 C 字 带 D 字

提示：判断完麦头类型后，可将包装里标配的防滑橡胶圈套在麦头上进行便捷区分。
