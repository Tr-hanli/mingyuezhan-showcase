🎓搭配不同相机的详细使用教程

Insta360 X5 全景相机 — 搭配隐形自拍杆可自动消除自拍杆痕迹

🌐 搭配全景相机（X6 / X5 / X4 / X3 / ONE RS / ONE X2 / ONE R / ONE X）

这是隐形自拍杆最经典的用法。搭配影石全景相机，自拍杆可在 360° 画面中完全隐形，轻松实现无人机般的第三人称跟拍效果。

1
安装相机 将全景相机底部的 1/4" 螺孔对准自拍杆顶部的 1/4" 螺口，顺时针旋紧固定。
2
调整角度（关键） 将相机与自拍杆保持在一条直线上，使自拍杆与相机镜头方向平行。这是实现隐形效果的核心要点。
3
旋紧旋钮 确保相机与自拍杆之间的连接稳固，拍摄过程中不要出现松动或倾斜。
4
保持稳定 拍摄过程中请保持自拍杆稳定，任何细微移动都可能影响隐形效果。建议双手握持或搭配省力握把使用。
5
开始拍摄 开启全景相机，选择全景录像模式（如 8K 30fps）。拍摄完成后，Insta360 的拼接算法会自动消除画面中的自拍杆，无需额外后期处理。
✅ 隐形效果原理
影石全景相机的两颗鱼眼镜头会同时捕捉 360° 画面。自拍杆恰好位于两颗镜头画面的重叠区域（盲区），通过专利图像拼接算法，自拍杆会被自动消除，呈现出「无人机跟拍」般的悬浮视角。
💡 拍摄技巧
• 将自拍杆举过头顶旋转一圈，可拍出酷炫的旋转转场效果。
• 延长自拍杆越长，视角越像无人机低空跟拍；使用 3m 超长自拍杆可拍出「世界很大，我很渺小」的震撼感（注意：超长自拍杆在全景画面中不能完全隐形）。
• 两个人出游时，可以让同伴像打地鼠一样上下晃悠自拍杆，拍出有趣的大头钉旅行转场。

🎬 搭配 Ace 系列相机（Ace Pro 2 / Ace Pro / Ace）

Ace 系列为平面运动相机，无法像全景相机那样在拍摄时直接隐形自拍杆，但可以通过后期处理实现自拍杆去除效果。

1
购买转接配件 需单独购买「磁吸快拆配件」或「1/4" 转三爪接头」，将 Ace 相机连接到隐形自拍杆上。
2
安装与拍摄 将 Ace 相机安装到自拍杆上，保持相机与自拍杆直线，进行拍摄。
3
后期去除自拍杆 打开 Insta360 App → 点击「剪辑」→ 选择「AI 创意库」→ 找到「自拍杆去除」→ 点击「使用模板」，即可自动去除画面中的自拍杆痕迹。
⚠️ 注意
• Ace 系列不支持拍摄时实时隐形，必须通过 Insta360 App 后期处理。
• 使用超长自拍杆时，由于自拍杆在广角画面中占比过大，后期去除效果可能不理想。
• 保持相机与自拍杆尽量在一条直线上，有助于提升后期去除成功率。

🤏 搭配 GO 系列相机（GO 3S / GO 3 / GO 2）

GO 系列为拇指相机，体积小巧，搭配隐形自拍杆非常适合随身记录。

Insta360 GO 3S — 搭配隐形自拍杆可拍摄第三人称 Vlog 视角
1
安装 GO 相机 GO 3S / GO 3 / GO 2 底部通常自带磁吸底座或可通过磁吸转接件连接到 1/4" 螺口。将相机磁吸到底座上，再旋紧到自拍杆顶部。
2
调整拍摄角度 GO 系列使用广角镜头，目前暂不支持自拍杆隐形。可通过调节拍摄角度，尽量让自拍杆位于画面边缘或被主体遮挡，减少自拍杆入镜。
3
拍摄 Vlog 视角 将自拍杆伸展至合适长度，手持自拍杆 walking POV 拍摄，可轻松获得自然的第三人称 Vlog 视角。

GO 系列相机（包括 GO 3S / GO 3 / GO 2）使用广角镜头拍摄时，暂不支持自拍杆隐形。如需完全消除自拍杆，建议使用全景相机拍摄。

全景相机隐形操作要点

1
保持直线 相机与自拍杆必须保持在一条直线上。若相机与自拍杆存在一定倾斜角度，自拍杆将无法被完全隐形。
2
避免充电线入画 若相机与自拍杆通过充电线连接，充电线的 USB 接口可能入画，导致无法完全隐形。
3
保持稳定 拍摄过程中请保持自拍杆稳定，任何细微移动都可能影响隐形效果。

保养步骤

1
立即冲洗 若接触过海水或在沙滩使用过，使用后需立即用淡水冲洗（防止金属被腐蚀生锈、管节被沙子卡住）。
2
展开管节 将自拍杆完全展开所有管节，确保内部水分可以流出。
3
甩水晾干 从底部排水口甩出水分，并将自拍杆放置在通风处完全晾干后再收纳。
4
避免残留 避免残留污渍或盐分损坏设备，晾干后检查管节伸缩是否顺畅。
💡 高强度款额外提示
高强度隐形自拍杆底部内置防沙过滤网，可有效阻挡沙粒进入杆体。使用后仍需按上述步骤清洗晾干，以保证过滤网通畅和杆体寿命。

⚠️使用注意事项

  • 高速运动场景：114cm 与 85cm 隐形自拍杆为轻量化设计，不适合高速冒险运动。摩托车、滑雪、极限运动等高强度场景请务必选择「高强度隐形自拍杆」。
  • 长自拍杆安全：切勿在高速或动作场景中使用长自拍杆（尤其是 114cm 展开后），以免相机因离心力或颠簸而跌落。
  • 稳定性：使用 ONE RS 一英寸全景版本时，建议只将自拍杆延长2节（约70cm）。
  • 转接配件：Ace 系列和 GO Ultra 使用隐形自拍杆时，必须购买对应的转接配件，否则无法安装。
  • 隐形限制：超长自拍杆（如 3m 版）在全景画面中不能完全隐形。
  • 充电线：若相机与自拍杆通过充电线连接拍摄，充电线的 USB 接口可能入画，导致无法完全隐形。
  • 海水腐蚀：接触过海水后必须立即用淡水冲洗，防止金属部件腐蚀生锈。
  • 官方出品：影石 Insta360 官方出品的隐形自拍杆经严格结构与可靠性测试，第三方山寨自拍杆可能无法实现隐形效果，且存在安全隐患。

❓常见问题 FAQ

Q1：为什么我的全景相机搭配隐形自拍杆后，画面中还能看到自拍杆？

可能原因：

  • 相机与自拍杆未保持在一条直线上，存在倾斜角度。
  • 使用了超长自拍杆（3m 等），超出算法处理范围。
  • 相机通过充电线与自拍杆连接，USB 接口入画。
  • 拍摄过程中自拍杆晃动过大，导致拼接算法失效。
  • 使用了非官方自拍杆，无法实现隐形算法。

Q2：Ace Pro 2 搭配隐形自拍杆，能不能像全景相机一样直接隐形？

不能。Ace 系列为平面运动相机，没有全景拼接算法。只能通过 Insta360 App 的「AI 创意库」→「自拍杆去除」进行后期处理。

Q3：GO 3S 能不能实现自拍杆隐形？

不能。GO 系列使用广角镜头，目前暂不支持自拍杆隐形。建议调整拍摄角度避免自拍杆入镜，或改用全景相机拍摄。

Q5：隐形自拍杆可以用于水下拍摄吗？

可以。114cm、85cm 和高强度隐形自拍杆均支持海水和淡水中使用。但使用后必须展开管节、清水冲洗并完全晾干，防止腐蚀和管节卡死。

Q6：高强度隐形自拍杆的「防沙过滤网」有什么用？

高强度隐形自拍杆底部内置防沙过滤网，可在沙滩、沙漠等环境中使用时阻挡沙粒进入杆体内部，避免管节被沙子卡住，延长使用寿命。

Q7：我可以在全景相机上使用 3m 超长自拍杆并期待完全隐形吗？

不能。超长自拍杆（普通版/升级版 3m）在全景画面中不能完全隐形。如需完全隐形，请使用 114cm 或 85cm 隐形自拍杆。
