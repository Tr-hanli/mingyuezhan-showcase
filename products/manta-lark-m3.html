猛玛 LARK M3 无线麦克风 — 产品资料文档

资料来源：https://www.hollyland.com.cn/support/lark-m3/ 品牌：HOLLYLAND 猛玛 整理日期：2026-08-12

一、产品概述

LARK M3 是猛玛推出的无线麦克风系统，支持最高 四发四收（4 个发射器 + 4 个接收器灵活组合），支持 32bit float 高规格收音、人声美化、智能混音等功能，适用于手机、相机、电脑等多场景收音需求。

系统组件： 1. 发射器 TX（麦克风） 2. 接收器 RX（分手机版 / 相机版） 3. 充电盒

四、常见问题（FAQ）

4.1 连接与配对

Q1：LARK M3 如何连接电脑？

方式一：通过 3.5mm 连接线连接 1. 通过 3.5mm TRS 转 TRRS 线连接到电脑的 3.5mm TRRS 接口，TRRS 端连接电脑，TRS 端连接接收器 3.5mm 口（台式电脑若是 TRS 录音接口，则需要 TRS 转 TRS 线连接）； 2. 在电脑麦克风选项中选择对应的外置麦克风选项。

方式二：通过 USB-C/USB-A 转 USB-C 线连接 1. 使用 USB-C/USB-A 转 USB-C 线连接电脑的 USB-C 或 USB-A 口与接收器的 USB-C 口； 2. 在电脑麦克风选项中选择【Wireless Microphone】。

Q2：LARK M3 手机版麦克风与接收器配对操作

  1. TX 关机状态下，长按侧边黄色按键 6 秒钟进入配对状态（此时 TX 指示灯显示蓝灯快速闪烁）；
  2. RX 长按底部黄色按键 3 秒钟进入配对状态（此时 RX 指示灯显示蓝灯快闪）；
  3. TX、RX 需同时进入配对状态，指示灯均蓝色快速闪烁表示配对中，指示灯变为常亮即配对成功。

Q3：LARK M3 相机版接收器与麦克风手动配对操作

  1. TX 关机状态下，长按侧边按键 6 秒钟进入配对状态（TX 指示灯蓝灯快速闪烁）；
  2. RX 长按左侧下方的配对按键 3 秒钟进入配对状态；
  3. TX、RX 需同时进入配对状态，指示灯均蓝色快速闪烁表示配对中，指示灯变为常亮即配对成功。

Q4：LARK M3 如何进行主从切换？

  1. RX 接收器与手机连接完成后，打开 APP，在顶部点击"Remote 手机 RX*"进入主从设备切换；
  2. 点击需要切换的从设备后方三个点，弹出切换 RX 接收器的主从设置图标，点击对应 RX 的切换图标，等待切换完成；
  3. 完成当前连接手机的 RX 接收器的主从切换后，即可在 APP 界面对当前连接的 RX 接收器及其 TX 设备进行参数调节。

Q5：如何判断当前接收器是主设备还是从设备？

方法一：根据指示灯判断 - 手机版接收器连接成功后：主 RX 的 TX 指示灯显示蓝色，从 RX 的 TX 指示灯显示黄色（灯光闪烁仅表示麦克风未完成连接）； - 相机版接收器连接成功后：主 RX 的 RX 状态灯显示蓝灯常亮，从 RX 的 RX 状态灯显示黄灯常亮。

方法二：通过 APP 显示判断 - 打开猛玛音频 APP，设备控制主界面显示 "Master" 标签的为主 RX，显示 "Remote" 标签的为从 RX。

Q6：为什么 LARK M3 发射器长按三下侧面按键无法正常控制手机开启录制？

使用该功能需要先关闭后台的【猛玛音频】APP；部分手机在关闭后台 APP 后功能仍无法生效，此时需要在关闭 APP 后重新插拔一次接收器即可正常使用。

4.2 功能与设置

Q7：LARK M3 如何调节输出音量大小？

相机版接收器： 1. 通过接收器上的拨杆调节输出音量，拨杆上方音量柱丝印图标对应音量大小（音量柱越高声音越大，越低声音越小）； 2. APP 内可对档位增益数值进行自定义设置。

手机版接收器： 1. 需通过连接至手机【猛玛音频】APP 调节输出音量大小； 2. 苹果版 APP 支持高、中、低三挡音量调节，安卓版 APP 支持 1~6 六档音量大小调节。

Q8：LARK M3 如何开启人声美化？

需将麦克风接收器连接至手机，通过【猛玛音频】APP 开启：

  1. 将麦克风接入手机（手机版接收器可直接插入手机，相机版接收器可通过 C to C 连接线连接）；
  2. 打开猛玛音频 APP 并连接设备，进入"美声设置"界面，可选择一键美声或专属美声。
模式 说明
一键美声 开启后所有已连接的 TX 发射器同步启用一键声音美化，后续新连接的 TX 也会自动开启；自动抑制人声齿音，让收音清晰干净
专属美声 支持根据实际使用需求调节声音美化参数，调节完成后可保存为专属模板，后续可快速套用；最多可同时独立应用在 4 个 TX 上；模板只跟随 APP 账号同步，无法跟随设备同步至其他手机 APP

Q9：LARK M3 人声美化功能支持四个 TX 分别应用不同的美化效果吗？

  • 开启【专属美声】时：支持 4 个 TX 独立应用已保存的美声效果，可个性化调整；
  • 开启【一键美声】时：所有已连接 TX 同步启用同一效果，不支持 4 个 TX 独立应用不同效果。

Q10：猛玛音频 APP 内"智能混音"功能具体有什么作用？

智能混音功能为多人收音场景设计。在使用多于 2 个麦克风 TX 收音时，打开智能混音可降低多人收音的环境噪音，同时突出 1 个主讲人的声音，确保主讲人收音清晰。（该功能仅支持单声道模式下使用）

4.3 系统能力与规格

Q11：LARK M3 支持几发几收？

LARK M3 最高支持 四发四收，在四发四收以内可灵活组合使用（例如：两发三收、四发一收等均可）。

Q12：LARK M3 多发多收时接收器可以相机版和手机版混用吗？

可以。多接收器同时使用时，支持相机版接收器和手机版接收器混用，只要在四个接收器以下，可灵活搭配。

Q13：LARK M3 使用苹果手机录制 32bit float 规格音频时，哪些软件可以支持？

可使用以下软件录制：Adobe Audition、n-Track Studio（iOS 版）、Audio Evolution Mobile、Ferrite Recording Studio、Apogee MetaRecorder、Cubasis / Auria Pro。

Q14：使用苹果手机打开 32bit float 录制格式，录制出来的音频仍然是 24bit？

LARK M3 支持录制 32bit float 规格音频，同时需要设备和软件本身均支持才可正常录制，否则将自动降低至 24bit 录制。由于软件本身限制，苹果手机录音机和原相机（录像）均不支持 32bit float 规格音频录制。

4.4 配件与升级

Q15：LARK M3 的热靴配件可以与 LARK MAX2 交叉使用吗？

由于 LARK M3 四音轨功能的加入，两款麦克风热靴配件的软硬件有差异：LARK M3 的热靴配件可以应用于 LARK MAX2，但 LARK MAX2 的热靴配件无法应用于 LARK M3。

Q16：LARK M3 如何进行升级？

  1. 确保所有需要升级的麦克风和接收器正常配对，将麦克风接收器与手机连接；
  2. 打开手机最新版【猛玛音频】APP，进入设备设置界面（第一次打开时务必将所有权限开放给 APP）；
  3. 进入功能设置界面后，点击右上角"齿轮"图标，进入"更多设置"界面；
  4. 在"更多设置"界面下滑到底部，点击进入"固件升级"菜单，即可查看对应设备的当前固件版本；
  5. 如有可更新固件，当前固件版本右侧会出现小红点提示，点击底部"一键升级"，等待 APP 通过网络自动下载安装最新固件包；
  6. 升级过程中指示灯呈现粉灯常亮状态，等待 3~5 分钟即可完成升级；升级成功后设备自动重启即结束；如升级失败可重复上述步骤。

Q17：LARK M3 热靴配件如何进行升级？

热靴配件需通过连接接收器和相机进行升级：

  1. 将热靴配件与相机版接收器通过 Type-C 接口连接；
  2. 将热靴配件接入相机热靴接口；
  3. 连接好后接收器自动识别热靴版本，如需升级，热靴将自动进入升级状态，此时接收器指示灯呈现粉灯常亮状态；
  4. 等待热靴升级完成，设备自动完成重启即可。

4.5 充电盒使用

Q18：LARK M3 充电盒开盒指引

LARK M3 充电盒带有锁扣设计，打开时需稍微用力按压中间圆形按钮，随后打开充电盒盖。
